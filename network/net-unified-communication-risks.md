RTP interception
Unencrypted signaling

SIP flooding
Caller ID spoofing
Meeting Hijacking
Unauthorized access
Link sharing abuse
Data Leakage
File sharing misuse
Screen sharing exposure
Identity Risks
Credential phishing
SSO compromise
Q2: Mitigation Controls
TLS & SRTP encryption
