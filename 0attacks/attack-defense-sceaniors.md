# Attack Scenarios – Prevention, Detection, and Response

| Attack Scenario | Prevention | Detection | Response |
|-----------------|------------|-----------|----------|
| **Network Communications**<br><br>• Large outbound data transfer to unusual external destinations<br>• Multiple connections to unauthorized or suspicious IP addresses within a short period<br>• Communication with known malicious IPs/domains (C2)<br>• Unusual network protocols or ports<br>• Beaconing activity | • Azure Firewall<br>• Network Security Groups (NSGs)<br>• Virtual Network Segmentation<br>• Azure VPN Gateway<br>• Private Endpoints<br>• Microsoft Defender for Cloud (Adaptive Network Hardening)<br>• DDoS Protection Standard | • Microsoft Defender for Cloud alerts<br>• Microsoft Sentinel analytics rules<br>• Azure Network Watcher<br>• NSG Flow Logs<br>• Azure Monitor Network Insights<br>• Threat Intelligence indicators<br>• Microsoft Defender XDR correlation | • Microsoft Sentinel Playbooks<br>• Block malicious IPs using Azure Firewall/NSGs<br>• Isolate affected systems<br>• Threat hunting<br>• Incident investigation<br>• IOC enrichment and containment<br>• Real-time alerting and notification |
| **Suspicious File Access**<br><br>• Mass file copy, move, or deletion<br>• Bulk download of sensitive files<br>• Access to unusual file types<br>• Unauthorized access to confidential files<br>• File encryption by unknown processes (Ransomware)<br>• Data exfiltration | • Microsoft Purview Information Protection (Sensitivity Labels)<br>• Microsoft Purview Data Loss Prevention (DLP)<br>• Least Privilege Access (RBAC)<br>• File Integrity Monitoring<br>• Microsoft Defender for Endpoint<br>• Controlled Folder Access | • Microsoft Defender for Endpoint alerts<br>• Microsoft Sentinel analytics<br>• Microsoft Purview Audit Logs<br>• Azure Activity Logs<br>• File Integrity Monitoring alerts<br>• UEBA anomaly detection | • Restore from Azure Backup<br>• Microsoft Defender for Endpoint device isolation<br>• Microsoft Sentinel playbooks<br>• Block user access<br>• Incident investigation<br>• File recovery<br>• Real-time alerts |
| **Suspicious Sign-ins**<br><br>• Login from unusual location or impossible travel<br>• Login from TOR or anonymous IPs<br>• Multiple failed sign-in attempts<br>• Password spraying<br>• Brute-force attacks<br>• Sign-in from risky devices | • Microsoft Entra Conditional Access<br>• Multi-Factor Authentication (MFA)<br>• Passwordless Authentication (FIDO2, Windows Hello)<br>• Account Lockout Policies<br>• Risk-Based Conditional Access<br>• Identity Protection | • Microsoft Entra ID Sign-in Logs<br>• Identity Protection Risk Detections<br>• Microsoft Defender for Identity alerts<br>• Microsoft Sentinel UEBA<br>• Impossible Travel detection<br>• Failed login analytics | • Disable or lock account<br>• Force password reset<br>• Revoke active sessions<br>• Microsoft Sentinel playbooks<br>• Incident investigation<br>• Real-time alerts |
| **Unauthorized Applications**<br><br>• Installation of unauthorized software<br>• Execution of unknown binaries<br>• Unauthorized system configuration changes<br>• Privilege escalation attempts<br>• Unsanctioned browser extensions | • Microsoft Intune Application Control<br>• Windows Defender Application Control (WDAC)<br>• AppLocker<br>• Microsoft Defender for Endpoint<br>• Least Privilege Administration | • Microsoft Defender for Endpoint alerts<br>• Microsoft Defender Vulnerability Management<br>• Microsoft Sentinel analytics<br>• Azure Monitor<br>• Device inventory changes | • Quarantine device<br>• Remove malicious application<br>• Roll back changes<br>• Threat hunting<br>• Microsoft Sentinel playbooks<br>• Notify SOC |
| **Privilege Escalation**<br><br>• Addition to privileged groups<br>• Unauthorized role assignment<br>• Elevation to Global Administrator<br>• Abuse of service accounts | • Privileged Identity Management (PIM)<br>• Least Privilege Access<br>• Just-In-Time (JIT) Access<br>• Conditional Access<br>• RBAC | • Microsoft Entra Audit Logs<br>• Microsoft Sentinel analytics<br>• Microsoft Defender for Identity<br>• Azure Activity Logs | • Remove elevated permissions<br>• Disable compromised accounts<br>• Revoke sessions<br>• Incident investigation<br>• Notify security team |
| **Malware / Ransomware**<br><br>• Malware execution<br>• Ransomware encryption<br>• Malicious PowerShell execution<br>• Living-off-the-Land (LOLBins) abuse | • Microsoft Defender Antivirus<br>• Microsoft Defender for Endpoint<br>• Attack Surface Reduction (ASR) Rules<br>• Application Control<br>• Email Protection | • Microsoft Defender for Endpoint<br>• Microsoft Defender XDR<br>• Microsoft Sentinel analytics<br>• Behavioral detection | • Device isolation<br>• Kill malicious processes<br>• Restore from backup<br>• IOC blocking<br>• Threat hunting |
| **Data Exfiltration**<br><br>• Uploading sensitive data to cloud storage<br>• Large outbound transfers<br>• USB data copy<br>• Emailing confidential files externally | • Microsoft Purview DLP<br>• Endpoint DLP<br>• Information Protection Labels<br>• Defender for Cloud Apps<br>• USB Device Control | • DLP alerts<br>• Defender for Cloud Apps<br>• Microsoft Sentinel analytics<br>• UEBA anomalies | • Block transfer<br>• Revoke user sessions<br>• Investigate affected accounts<br>• Notify data owner |
| **Persistence Mechanisms**<br><br>• Scheduled task creation<br>• Startup folder modification<br>• Registry Run key changes<br>• Service creation | • Endpoint hardening<br>• Attack Surface Reduction Rules<br>• Least Privilege<br>• Application Control | • Microsoft Defender for Endpoint<br>• Microsoft Sentinel<br>• Windows Security Events | • Remove persistence<br>• Isolate endpoint<br>• Threat hunting<br>• Full forensic investigation |
| **Credential Theft**<br><br>• Credential dumping<br>• Pass-the-Hash<br>• Pass-the-Ticket<br>• LSASS access | • Credential Guard<br>• Windows Defender<br>• Microsoft Defender for Endpoint<br>• Local Administrator Password Solution (LAPS) | • Microsoft Defender for Endpoint<br>• Microsoft Defender for Identity<br>• Microsoft Sentinel analytics | • Reset credentials<br>• Rotate privileged passwords<br>• Revoke sessions<br>• Investigate compromised systems |
| **Cloud Resource Misconfiguration**<br><br>• Public storage accounts<br>• Exposed management ports<br>• Missing encryption<br>• Weak NSG rules<br>• Excessive permissions | • Azure Policy<br>• Microsoft Defender for Cloud<br>• Secure Score<br>• Landing Zone Governance<br>• Infrastructure as Code (Terraform/Bicep) | • Defender for Cloud recommendations<br>• Azure Policy compliance<br>• Microsoft Sentinel<br>• Azure Resource Graph | • Remediate configuration<br>• Apply Azure Policy<br>• Close exposed ports<br>• Review access permissions |
| **Insider Threat**<br><br>• Unusual administrative activity<br>• Access outside business hours<br>• Bulk download of confidential data<br>• Policy violations | • Least Privilege Access<br>• Segregation of Duties<br>• Microsoft Purview<br>• Conditional Access<br>• Insider Risk Management | • UEBA in Microsoft Sentinel<br>• Microsoft Purview Audit<br>• Insider Risk alerts<br>• Defender XDR | • Suspend account<br>• Investigate activity<br>• Preserve evidence<br>• Escalate to HR/Security |
| **Email & Phishing Attacks**<br><br>• Malicious attachments<br>• Phishing emails<br>• Business Email Compromise (BEC)<br>• QR code phishing | • Microsoft Defender for Office 365<br>• Safe Links<br>• Safe Attachments<br>• Anti-Phishing Policies<br>• User Awareness Training | • Defender for Office 365 alerts<br>• Microsoft Sentinel analytics<br>• Defender XDR incidents | • Remove malicious emails<br>• Block sender/domain<br>• Reset compromised accounts<br>• User notification and investigation |
