* User, group names and passwords

* Routing tables
* SNMP information
* System Names and architecture and system types.

Used to identify specific system characteristics and users:
•	System Banners: From services like FTP, SSH, HTTP headers
•	Operating System/Architecture: OS types, architectures, remote system profiles
•	Routing Tables: Understanding internal network paths
•	SNMP Data: From public community strings (if misconfigured)
•	Hostnames/System Names: Naming patterns or conventions
•	User and Group Names: Enumerated from services or leaked configs
•	Stored Credentials: Passwords (hashed/plaintext) if discovered
•	System Enumeration: Inventory of systems and components
