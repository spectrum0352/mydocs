# TYPES OF PRIVACY CONSENT

## OPT-IN CONSENT
USERS MUST TAKE ACTION TO ALLOW THEIR DATA TO BE COLLECTED OR PROCESSED.

## OPT-OUT CONSENT
DATA COLLECTION IS ALLOWED BY DEFAULT, BUT USERS CAN CHOOSE TO DENY PERMISSION

## INFORMED CONSENT
USERS ARE INFORMED HOW THEIR DATA WILL BE USED BEFORE GIVING CONSENT.

## GRANULAR CONSENT
USERS CAN CHOOSE WHAT DATA THEY ALLOW TO BE COLLECTED OR PROCESSED.

## CONDITIONAL CONSENT
USER CONSENTS TO RECEIVE MARKETING MESSAGES FOR ACCESSING A FREE DOWNLOAD.

## WITHDRAWABLE CONSENT
USERS MUST BE ABLE TO WITHDRAW CONSENT ANYTIME, HALTING ALL DATA PROCESSING

## EXPLICIT CONSENT
USERS ACTIVELY CONSENT TO DATA PROCESSING BY SELECTING A CHECKBOX
