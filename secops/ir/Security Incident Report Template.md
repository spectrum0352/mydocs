Remediation: [e.g., "Global password reset forced for all administrative accounts."]
Recovery: [e.g., "System restored from off-site backups; security patches applied."]

Primary Vulnerability: [e.g., "Lack of Multi-Factor Authentication (MFA) on an older VPN gateway."]
