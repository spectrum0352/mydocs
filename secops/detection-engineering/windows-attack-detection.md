# Windows Threat Detection Engineering Event Reference

Here is th **Windows Threat Detection Engineering Event Reference**. Here are the events provided, corrected inaccurate descriptions, and added high-value events that are important for detecting **credential attacks, lateral movement, persistence, privilege escalation, defense evasion, process execution, PowerShell abuse, Active Directory attacks, and network-based attacks**.

Microsoft's current Sentinel guidance also identifies many of these events—including 1102, 4624/4625, 4657, 4663, 4688, 4700/4702, 4719, account-management events, and firewall events—as useful Windows security events for Sentinel collection. ([Microsoft Learn][1])

### Windows Threat Detection Engineering – Security Event Reference

| Event ID | Windows Log / Category               | What the Event Means                                                                     | Threat / Attack Relevance                                            | How It Is Used in Threat Detection Engineering                                                                                                                                                                                                                                              |
| -------- | ------------------------------------ | ---------------------------------------------------------------------------------------- | -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1102** | Security – Audit Log                 | The Windows Security audit log was cleared.                                              | **Defense evasion / evidence destruction**                           | Alert on any Security log clearing. Correlate with the initiating account, host, process creation and preceding administrative activity. Treat unexpected clearing on servers/DCs as high severity.                                                                                         |
| **4608** | Security – System Integrity          | Windows is starting up.                                                                  | System lifecycle event                                               | Establish host boot timelines and correlate suspicious activity immediately after reboot.                                                                                                                                                                                                   |
| **4616** | Security – System Integrity          | System time was changed.                                                                 | **Defense evasion / timestamp manipulation**                         | Detect attempts to alter timestamps or disrupt authentication/log correlation. Correlate with privileged account activity and process execution.                                                                                                                                            |
| **4624** | Security – Logon                     | An account successfully logged on.                                                       | **Initial access / credential abuse / lateral movement**             | Core authentication telemetry. Analyze `LogonType`, source IP, workstation, target account, authentication package and time. Detect unusual RDP, SMB, WinRM, service and network logons.                                                                                                    |
| **4625** | Security – Logon                     | An account failed to log on.                                                             | **Brute force / password spraying / credential attacks**             | Detect repeated failures by source IP, account, host or time window. Correlate with subsequent 4624 to identify successful compromise following brute force.                                                                                                                                |
| **4634** | Security – Logoff                    | An account logged off.                                                                   | Session tracking                                                     | Correlate with 4624 to establish session duration and identify abnormal session behavior. Lower value as a standalone detection.                                                                                                                                                            |
| **4647** | Security – Logoff                    | A user initiated a logoff.                                                               | Session tracking                                                     | Correlate with 4624/4634. Useful for reconstructing interactive sessions and attacker timelines.                                                                                                                                                                                            |
| **4648** | Security – Logon                     | A logon was attempted using **explicit credentials**.                                    | **Credential abuse / lateral movement**                              | Detect use of alternate credentials, especially from unusual hosts or by privileged accounts. Correlate with 4688 to identify `runas`, remote administration tools or suspicious processes.                                                                                                 |
| **4672** | Security – Special Privilege Use     | Special privileges were assigned to a new logon.                                         | **Privilege escalation / privileged access**                         | Detect privileged logons and correlate with 4624. Particularly important for Domain Admin, local Administrator, SYSTEM and other highly privileged identities.                                                                                                                              |
| **4670** | Security – Object Access             | Permissions on an object were changed.                                                   | **Privilege escalation / persistence / defense evasion**             | Detect changes to ACLs on sensitive files, folders, registry keys and AD objects. Baseline legitimate administrative changes.                                                                                                                                                               |
| **4688** | Security – Process Creation          | A new process was created.                                                               | **Execution / persistence / privilege escalation / defense evasion** | One of the most important Windows detection events. Detect PowerShell, cmd, rundll32, regsvr32, mshta, wscript, cscript, certutil, encoded commands and suspicious parent-child process relationships. Command-line auditing should be enabled.                                             |
| **4689** | Security – Process Termination       | A process terminated.                                                                    | Defense evasion / process tracking                                   | Correlate with 4688 to reconstruct process execution. Useful for detecting short-lived malicious processes and abnormal process termination.                                                                                                                                                |
| **4697** | Security – System Integrity          | A new service was installed on the system.                                               | **Persistence / privilege escalation / lateral movement**            | High-value service persistence detection. Investigate service name, executable path, account and initiating user. Correlate with 4688 and 7045.                                                                                                                                             |
| **4698** | Security – Scheduled Task            | A scheduled task was created.                                                            | **Persistence / execution**                                          | Detect newly created tasks, especially tasks executing PowerShell, scripts, LOLBins or binaries from unusual directories.                                                                                                                                                                   |
| **4699** | Security – Scheduled Task            | A scheduled task was deleted.                                                            | **Defense evasion / cleanup**                                        | Detect deletion of suspicious tasks after execution. Microsoft specifically recommends monitoring scheduled-task deletion because attackers can use tasks for persistence and cleanup. ([Microsoft Learn][2])                                                                               |
| **4700** | Security – Scheduled Task            | A scheduled task was enabled.                                                            | **Persistence / execution**                                          | Detect previously disabled malicious tasks being activated. Correlate with 4698/4702 and process creation.                                                                                                                                                                                  |
| **4701** | Security – Scheduled Task            | A scheduled task was disabled.                                                           | **Defense evasion / persistence manipulation**                       | Detect disabling of security, backup or administrative tasks. Also correlate with subsequent malicious activity.                                                                                                                                                                            |
| **4702** | Security – Scheduled Task            | A scheduled task was updated.                                                            | **Persistence modification**                                         | Detect modification of legitimate scheduled tasks to execute malicious commands or binaries.                                                                                                                                                                                                |
| **4719** | Security – Audit Policy Change       | System audit policy was changed.                                                         | **Defense evasion**                                                  | High-priority detection. Attackers may reduce auditing before conducting additional activity. Alert on unexpected changes and correlate with administrator identity and 4688. Microsoft notes that this event is generated when the computer's audit policy changes. ([Microsoft Learn][3]) |
| **4720** | Security – Account Management        | A user account was created.                                                              | **Persistence / privilege escalation**                               | Detect unexpected account creation, especially privileged accounts or accounts created outside normal provisioning processes.                                                                                                                                                               |
| **4722** | Security – Account Management        | A user account was enabled.                                                              | **Persistence / account takeover**                                   | Detect reactivation of disabled accounts, particularly privileged, dormant or service accounts.                                                                                                                                                                                             |
| **4723** | Security – Account Management        | An attempt was made to change an account password.                                       | **Credential attack / account takeover**                             | Detect unusual password changes, particularly for privileged accounts or immediately before/after suspicious authentication activity.                                                                                                                                                       |
| **4724** | Security – Account Management        | An attempt was made to reset an account password.                                        | **Account takeover / privilege abuse**                               | High-value when a privileged administrator resets another user's password unexpectedly. Correlate with 4624 and account-management events.                                                                                                                                                  |
| **4725** | Security – Account Management        | A user account was disabled.                                                             | **Defense evasion / account manipulation**                           | Detect unauthorized disabling of security/admin accounts or accounts used by monitoring systems.                                                                                                                                                                                            |
| **4726** | Security – Account Management        | A user account was deleted.                                                              | **Defense evasion / persistence cleanup**                            | Detect deletion of accounts following compromise or removal of forensic evidence.                                                                                                                                                                                                           |
| **4728** | Security – Security Group Management | A member was added to a security-enabled **global** group.                               | **Privilege escalation / persistence**                               | High-value AD detection. Alert when users are added to privileged groups such as Domain Admins, Enterprise Admins or other sensitive groups.                                                                                                                                                |
| **4729** | Security – Security Group Management | A member was removed from a security-enabled global group.                               | Defense evasion / privilege manipulation                             | Detect unauthorized removal of security controls or changes made during attacker cleanup.                                                                                                                                                                                                   |
| **4732** | Security – Security Group Management | A member was added to a security-enabled **local** group.                                | **Privilege escalation / persistence**                               | Detect additions to local Administrators, Remote Desktop Users and other sensitive groups.                                                                                                                                                                                                  |
| **4733** | Security – Security Group Management | A member was removed from a security-enabled local group.                                | Privilege/group manipulation                                         | Detect unexpected changes to local privileged groups.                                                                                                                                                                                                                                       |
| **4735** | Security – Security Group Management | A security-enabled local group was changed.                                              | **Privilege escalation / security configuration change**             | Monitor changes to privileged local groups and correlate with 4728/4732 and administrative logons.                                                                                                                                                                                          |
| **4737** | Security – Security Group Management | A security-enabled global group was changed.                                             | **AD privilege manipulation**                                        | Detect modification of sensitive global groups and correlate with group membership changes.                                                                                                                                                                                                 |
| **4738** | Security – Account Management        | A user account was changed.                                                              | **Persistence / account takeover**                                   | Monitor changes to privileged accounts, UPN, group membership-related attributes, account settings and other sensitive attributes.                                                                                                                                                          |
| **4739** | Security – Policy Change             | Domain policy was changed.                                                               | **Defense evasion / domain compromise**                              | Detect unexpected domain-level policy changes. Important on domain controllers.                                                                                                                                                                                                             |
| **4740** | Security – Account Management        | A user account was locked out.                                                           | **Brute force / password spraying / credential attack**              | Detect abnormal lockout spikes. Identify source workstation responsible for repeated authentication failures.                                                                                                                                                                               |
| **4767** | Security – Account Management        | A user account was unlocked.                                                             | **Account manipulation**                                             | Detect unauthorized unlocking of privileged or dormant accounts.                                                                                                                                                                                                                            |
| **4768** | Security – Kerberos Authentication   | A Kerberos authentication ticket (TGT) was requested.                                    | **Credential theft / Kerberos abuse**                                | Baseline TGT requests and detect unusual encryption types, source hosts, privileged accounts and anomalous authentication patterns.                                                                                                                                                         |
| **4769** | Security – Kerberos Authentication   | A Kerberos service ticket (TGS) was requested.                                           | **Kerberoasting / lateral movement / service access**                | Important for detecting abnormal service-ticket requests, especially high-volume requests against service accounts.                                                                                                                                                                         |
| **4771** | Security – Kerberos Authentication   | Kerberos pre-authentication failed.                                                      | **Password spraying / brute force / credential attacks**             | Detect repeated failures by account/source and correlate with 4625 and 4768.                                                                                                                                                                                                                |
| **4772** | Security – Kerberos Authentication   | A Kerberos authentication ticket request failed.                                         | **Credential attack / authentication abuse**                         | Detect abnormal Kerberos failures and correlate with source host, user and 4771/4768.                                                                                                                                                                                                       |
| **4776** | Security – Credential Validation     | Domain Controller attempted to validate account credentials.                             | **NTLM authentication / credential attack**                          | Monitor NTLM authentication and identify excessive or unusual credential validation attempts.                                                                                                                                                                                               |
| **4777** | Security – Credential Validation     | Domain Controller failed to validate credentials for an account.                         | **Credential attack / authentication failure**                       | Detect abnormal NTLM credential validation failures and correlate with 4625 and source systems.                                                                                                                                                                                             |
| **4782** | Security – Account Management        | A user's password hash was accessed.                                                     | **Credential theft / credential dumping**                            | High-severity detection when occurring unexpectedly. Investigate the accessing account, host and surrounding credential-access activity.                                                                                                                                                    |
| **4798** | Security – Account Management        | A user's local group membership was enumerated.                                          | **Discovery**                                                        | Detect unusual enumeration of local group membership by scripts, malware or remote administration activity.                                                                                                                                                                                 |
| **4799** | Security – Account Management        | A security-enabled local group membership was enumerated.                                | **Discovery / privilege reconnaissance**                             | Detect reconnaissance for local administrators and privileged groups.                                                                                                                                                                                                                       |
| **4800** | Security – Workstation               | Workstation was locked.                                                                  | Session tracking                                                     | Establish endpoint activity timelines and identify unusual lock/unlock patterns.                                                                                                                                                                                                            |
| **4801** | Security – Workstation               | Workstation was unlocked.                                                                | Session tracking                                                     | Correlate with 4624 to establish interactive-user activity.                                                                                                                                                                                                                                 |
| **5136** | Security – Directory Service Changes | An AD object was modified.                                                               | **AD persistence / privilege escalation / defense evasion**          | Extremely valuable for monitoring modifications to users, groups, computers, GPOs and sensitive AD attributes. Microsoft identifies 5136 as a Directory Service Changes event. ([Microsoft Learn][4])                                                                                       |
| **5137** | Security – Directory Service Changes | A new AD object was created.                                                             | **Persistence / AD compromise**                                      | Detect creation of suspicious users, groups, computers, GPO-related objects and other directory objects.                                                                                                                                                                                    |
| **5139** | Security – Directory Service Changes | An AD object was moved.                                                                  | **AD manipulation**                                                  | Detect suspicious movement of sensitive objects between OUs/containers.                                                                                                                                                                                                                     |
| **5141** | Security – Directory Service Changes | An AD object was deleted.                                                                | **Defense evasion / AD manipulation**                                | Detect deletion of accounts, groups, computers or other sensitive directory objects.                                                                                                                                                                                                        |
| **5140** | Security – Network Share             | A network share was accessed.                                                            | **Lateral movement / data access**                                   | Detect SMB access to administrative shares such as `ADMIN$`, `C$` and `IPC$`, particularly from unusual hosts.                                                                                                                                                                              |
| **5145** | Security – Network Share             | A network share object was checked to determine whether requested access can be granted. | **Lateral movement / data discovery**                                | More granular SMB telemetry. Detect suspicious access to sensitive shares and unusual source/destination relationships.                                                                                                                                                                     |
| **4657** | Security – Object Access             | A registry value was modified.                                                           | **Persistence / defense evasion / configuration tampering**          | Detect modifications to security-sensitive registry locations, Run/RunOnce keys, services, Defender settings and execution-related registry locations.                                                                                                                                      |
| **4662** | Security – Directory Service Access  | An operation was performed on an AD object.                                              | **AD reconnaissance / DCSync / privilege abuse**                     | Critical for detecting sensitive AD operations. Build detections around replication-related GUIDs and access to sensitive objects. Defender for Identity requires this telemetry for DC monitoring. ([Microsoft Learn][5])                                                                  |
| **4663** | Security – Object Access             | An attempt was made to access an object.                                                 | **File access / data theft / defense evasion**                       | Detect access to sensitive files, credential stores, security configuration and other protected objects when SACLs are configured.                                                                                                                                                          |
| **4670** | Security – Object Access             | Permissions on an object were changed.                                                   | **Privilege escalation / persistence**                               | Detect ACL manipulation on files, folders, registry keys and other sensitive objects.                                                                                                                                                                                                       |
| **4946** | Security – Windows Firewall          | A Windows Firewall rule was added.                                                       | **Defense evasion / persistence / network access**                   | Detect creation of inbound/outbound firewall exceptions. Investigate rule name, ports, program and profile. Note: local rule changes generate this event; GPO-added rules do not. ([Microsoft Learn][6])                                                                                    |
| **4947** | Security – Windows Firewall          | A Windows Firewall rule was modified.                                                    | **Defense evasion**                                                  | Detect modification of existing firewall rules to permit malicious traffic.                                                                                                                                                                                                                 |
| **4948** | Security – Windows Firewall          | A Windows Firewall rule was deleted.                                                     | **Defense evasion**                                                  | Detect deletion of protective firewall rules or cleanup of attacker-created rules.                                                                                                                                                                                                          |
| **4950** | Security – Windows Firewall          | Windows Firewall settings were changed.                                                  | **Defense evasion**                                                  | Detect changes to firewall configuration, profiles and security settings.                                                                                                                                                                                                                   |
| **4954** | Security – Windows Firewall          | Windows Firewall Group Policy settings were changed.                                     | **Defense evasion / centralized control tampering**                  | Monitor unexpected firewall policy changes, particularly on servers and domain controllers.                                                                                                                                                                                                 |
| **5025** | System – Windows Firewall            | Windows Firewall service was stopped.                                                    | **Defense evasion**                                                  | High-priority detection when the firewall service is stopped unexpectedly.                                                                                                                                                                                                                  |
| **5031** | Security – Windows Firewall          | Windows Firewall blocked an application from accepting incoming network traffic.         | **Network attack / suspicious listening service**                    | Detect unexpected applications attempting to accept inbound connections. Correlate with 4688 and 5155/5157.                                                                                                                                                                                 |
| **5152** | Security – WFP                       | Windows Filtering Platform blocked a network packet.                                     | **Network attack / reconnaissance**                                  | Detect blocked traffic and identify suspicious source/destination/port patterns. Useful for network reconnaissance and lateral movement analytics.                                                                                                                                          |
| **5153** | Security – WFP                       | Windows Filtering Platform blocked a packet because of a filter.                         | Network security enforcement                                         | Use for detailed firewall/WFP analytics and correlation with suspicious connection attempts.                                                                                                                                                                                                |
| **5155** | Security – WFP                       | Windows Filtering Platform blocked an application from listening on a port.              | **Malware / unauthorized service / network persistence**             | Detect unexpected applications attempting to create listening sockets. Correlate process path, signer and 4688.                                                                                                                                                                             |
| **5157** | Security – WFP                       | Windows Filtering Platform blocked a connection.                                         | **Network communication / C2 / lateral movement**                    | Detect repeated blocked connections to suspicious IPs, ports or destinations. Correlate with threat intelligence and process telemetry.                                                                                                                                                     |
| **5159** | Security – WFP                       | Windows Filtering Platform blocked an application from binding to a local port.          | **Network persistence / unauthorized listener**                      | Detect suspicious applications attempting to bind local ports.                                                                                                                                                                                                                              |
| **5447** | Security – WFP                       | A Windows Filtering Platform filter was changed.                                         | **Defense evasion / firewall manipulation**                          | Detect creation, modification or removal of WFP filters that could bypass network security controls.                                                                                                                                                                                        |

### Additional high-value Windows telemetry for detection engineering

The original list is strong, but **it is not sufficient by itself for an enterprise Windows threat-detection program**. The following telemetry should also be considered mandatory/high-value depending on the detection objective.

| Event / Telemetry                              | What It Detects                                   | How It Should Be Used                                                                                                                            |
| ---------------------------------------------- | ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| **7045 – System**                              | New Windows service installed                     | Detect service-based persistence and lateral movement. Correlate with Security 4697 and 4688.                                                    |
| **4103 – PowerShell**                          | PowerShell module logging                         | Detect PowerShell cmdlet execution and suspicious administrative activity.                                                                       |
| **4104 – PowerShell**                          | PowerShell Script Block Logging                   | **Critical for PowerShell threat detection.** Detect encoded commands, download cradles, credential theft, reconnaissance and malicious scripts. |
| **4105 / 4106 – PowerShell**                   | PowerShell script start/stop                      | Correlate script execution and user/session context.                                                                                             |
| **400 / 403 – PowerShell**                     | PowerShell engine lifecycle                       | Useful for establishing PowerShell execution timelines.                                                                                          |
| **4688 + CommandLine**                         | Process execution with command line               | Primary endpoint execution telemetry. Required for high-fidelity LOLBin and malware detections.                                                  |
| **Sysmon 1**                                   | Process creation                                  | Enhanced process telemetry including hashes, parent process and command line.                                                                    |
| **Sysmon 3**                                   | Network connection                                | Correlate process → destination IP/port for C2 and lateral movement.                                                                             |
| **Sysmon 7**                                   | Image/DLL loaded                                  | Detect suspicious DLL loading and injection-related activity.                                                                                    |
| **Sysmon 8**                                   | CreateRemoteThread                                | Useful for process injection detection.                                                                                                          |
| **Sysmon 10**                                  | Process access                                    | Detect credential dumping and process injection patterns.                                                                                        |
| **Sysmon 11**                                  | File creation                                     | Detect dropped payloads, scripts and suspicious files.                                                                                           |
| **Sysmon 12/13/14**                            | Registry changes                                  | Detect persistence and security-control tampering.                                                                                               |
| **Sysmon 22**                                  | DNS query                                         | Detect suspicious domains, DGA, C2 and malware infrastructure.                                                                                   |
| **4768/4769/4771**                             | Kerberos activity                                 | Detect Kerberoasting, abnormal authentication, password attacks and lateral movement.                                                            |
| **4776**                                       | NTLM credential validation                        | Detect NTLM abuse, password spraying and unusual authentication paths.                                                                           |
| **5136**                                       | AD object modification                            | Detect AD persistence and privilege manipulation.                                                                                                |
| **4662**                                       | AD object access                                  | Detect sensitive AD operations, including replication abuse/DCSync patterns.                                                                     |
| **4741 / 4743**                                | Computer account created/deleted                  | Detect suspicious computer-account creation and AD persistence.                                                                                  |
| **4726**                                       | User deleted                                      | Detect account cleanup and defense evasion.                                                                                                      |
| **4756 / 4757 / 4758**                         | Universal security group changes                  | Detect privileged-group manipulation.                                                                                                            |
| **4727 / 4731 / 4754**                         | Security group creation                           | Detect creation of attacker-controlled security groups.                                                                                          |
| **4780 / 4781**                                | Sensitive account ACL/name changes                | Detect manipulation of protected accounts.                                                                                                       |
| **4765 / 4766**                                | SID History added / failed                        | **Important AD privilege-escalation detection.** Detect SIDHistory abuse.                                                                        |
| **5376 / 5377**                                | Credential Manager credentials backed up/restored | Detect credential theft or suspicious credential recovery activity.                                                                              |
| **5148 / 5149**                                | WFP detected/subsided DoS activity                | Detect network denial-of-service behavior.                                                                                                       |
| **Windows Defender operational logs**          | Malware/PUA/ASR detections and remediation        | Correlate endpoint protection alerts with process, file and network telemetry.                                                                   |
| **Windows Defender Firewall operational logs** | Network enforcement                               | Correlate blocked/allowed traffic with process and endpoint activity.                                                                            |

Microsoft's current guidance for Defender for Identity specifically calls out events such as **4662, 4726, 4728, 4729, 4730, 4732, 4733, 4741, 4743 and 4756**, demonstrating why AD-focused detection should go beyond the original list. ([Microsoft Learn][5])

## Detection-engineering correlation model

A mature detection should **not normally alert on an individual Windows Event ID in isolation**. The event should be treated as a telemetry primitive and correlated with identity, endpoint, process, network and threat-intelligence context.

| Detection Scenario                      | Primary Events                        | Correlation / Detection Logic                                                                       |
| --------------------------------------- | ------------------------------------- | --------------------------------------------------------------------------------------------------- |
| **Brute force → successful compromise** | 4625 → 4624                           | Multiple failures from same source/account followed by successful authentication.                   |
| **Password spraying**                   | 4625, 4771, 4776                      | Same source attempts authentication against many accounts with relatively low attempts per account. |
| **Suspicious RDP**                      | 4624 + LogonType 10 + 4688            | RDP logon followed by unusual process execution or lateral movement.                                |
| **SMB lateral movement**                | 4624 + LogonType 3 + 5140/5145 + 4688 | Network logon followed by administrative-share access and remote execution.                         |
| **Privilege escalation**                | 4624 + 4672 + 4728/4732/4756          | Privileged logon combined with sensitive group membership change.                                   |
| **Account persistence**                 | 4720 → 4722 → 4732/4728               | Newly created/enabled account subsequently added to a privileged group.                             |
| **Credential attack**                   | 4648 + 4624 + 4688                    | Explicit credentials followed by successful authentication and suspicious process execution.        |
| **Kerberoasting**                       | 4769                                  | Abnormal volume of TGS requests, particularly for service accounts, from unusual hosts.             |
| **NTLM abuse**                          | 4776 + 4624                           | Unusual NTLM authentication patterns or authentication from unexpected systems.                     |
| **DCSync**                              | 4662 + privileged account context     | Detect directory replication-related access to domain objects.                                      |
| **Scheduled-task persistence**          | 4698/4702 → 4688                      | New/modified task followed by suspicious executable/script execution.                               |
| **Service persistence**                 | 4697/7045 → 4688                      | New service followed by execution of an unusual binary.                                             |
| **PowerShell attack**                   | 4688 + 4104                           | PowerShell process plus malicious/obfuscated script block.                                          |
| **Defense evasion**                     | 4719 / 1102 / 4616                    | Audit policy change, log clearing or time manipulation followed by suspicious activity.             |
| **Firewall tampering**                  | 4946/4947/4948/4950/4954/5447         | Firewall/WFP modification followed by network connections or inbound access.                        |
| **C2 activity**                         | 4688 + Sysmon 3/22 + 5157             | Suspicious process communicates with unusual external IP/domain.                                    |
| **Malicious registry persistence**      | 4657 + 4688                           | Registry modification followed by execution from suspicious location.                               |
| **AD persistence**                      | 5136 + 4720/4728/4732                 | Directory-object modification combined with account/group manipulation.                             |
| **Defense evasion cleanup**             | 1102 + 4699 + 4689                    | Security log clearing/task deletion/process termination following suspicious execution.             |

### Recommended detection-engineering priorities

For an enterprise **Microsoft Sentinel + Defender** environment, I would prioritize the telemetry roughly as follows:

| Priority          | Telemetry                    | Detection Value                                                        |
| ----------------- | ---------------------------- | ---------------------------------------------------------------------- |
| **P0 – Critical** | 4624, 4625, 4688, 4672       | Authentication, failed authentication, execution and privilege context |
| **P0 – Critical** | 1102, 4719                   | Security log/audit-policy tampering                                    |
| **P0 – Critical** | 4720, 4724, 4728, 4732, 4756 | Account creation/reset and privileged-group manipulation               |
| **P0 – Critical** | 4662, 5136                   | AD attack and directory manipulation                                   |
| **P0 – Critical** | 4768, 4769, 4771, 4776       | Kerberos/NTLM attack detection                                         |
| **P1 – High**     | 4697, 7045                   | Service persistence                                                    |
| **P1 – High**     | 4698–4702                    | Scheduled-task persistence                                             |
| **P1 – High**     | 4103/4104 + 4688             | PowerShell attack detection                                            |
| **P1 – High**     | 4657, 4670, 4663             | Registry, ACL and object manipulation                                  |
| **P1 – High**     | 4946–4954, 5025, 5447        | Firewall/WFP tampering                                                 |
| **P1 – High**     | 5140, 5145                   | SMB/lateral movement                                                   |
| **P2 – Medium**   | 4634, 4647, 4689, 4800, 4801 | Session reconstruction and investigation                               |
| **P2 – Medium**   | 5152, 5153, 5155, 5157, 5159 | Network enforcement and supporting network detections                  |

**Important correction:** the original statement "`4697 4698, 4699, 4700, 4701, 4702` – events related to Windows scheduled tasks" combines two different telemetry areas. **4697 is service installation**, whereas **4698–4702 are scheduled-task events**. In addition, **7045** from the System log is highly useful for service-installation detection. Microsoft documents 4698–4702 specifically under scheduled-task auditing. ([Microsoft Learn][7])

For Sentinel, this can be implemented as a layered detection architecture: **Windows Security Events → Sysmon/PowerShell → Defender telemetry → Sentinel analytics rules → entity/behavior correlation → incident fusion → automated response**. Microsoft also provides a current Windows Security Event reference specifically for selecting event sets for Sentinel collection. ([Microsoft Learn][1])
