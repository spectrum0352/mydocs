## Hashing in Microsoft

## Hash types used in Microsoft products

Microsoft Azure and Windows utilize various hashing algorithms depending on the context:

Microsoft Entra:  Passwords are hashed using a combination of MD4, PBKDF2, HMAC-SHA256, and salting techniques.

Windows Cryptographic Services : Commonly supported algorithms include MD5, SHA-1, and the SHA-2 family (SHA-256, SHA-384, SHA-512).

Windows Autopilot : Hardware hashes are used for device registration.
