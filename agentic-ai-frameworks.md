# Agentic AI Frameworks

## Langchain
Purpose: LLM Apps and Agents
Strengths: Large ecosystem, Modular, Strong community
Weakness: Debugging is hard
Best for: RAG, AI Workflows, Agents

## LlamaIndex
Purpose: LLM Apps and Agents
Strengths: Optimized search, Easy DB integration
Weakness: Less tools compared to Langchain
Best for: Document search, Chatbot memory

## CrewAI
Purpose: Multi-agent orchestration
Strengths: Simple setup, Task delegation
Weakness: Fewer integrations
Best for: AI teamwork, Automation

## Swarm
Purpose: Decentralized AI agents
Strengths: Distributed execution
Weakness: Niche use, Low adoption
Best for: Self organizing AI systems

## PydanticAI
Purpose: AI driven data validation
Strengths: Enforces structured LLM Outputs
Weakness: Limited scope
Best for: Schema validation, structured data


## LangGraph

Purpose: AI driven data validation
Strengths: Enforces structured LLM Outputs
Weakness: Limited scope
Best for: Schema validation, structured data
