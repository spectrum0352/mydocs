# Cloud Security Monitoring Tools

Here is a structured and detailed overview of Cloud Security Monitoring Tools, organized by category with explanations and visuals for better understanding.

☁️ 1. Digital Workspace Security
Image

Image

Image

Image

Purpose:
Secure collaboration and productivity platforms used by employees.

What It Covers:
Email security (anti-phishing, anti-malware)

Secure file sharing

DLP (Data Loss Prevention)

Conditional access

MFA enforcement

Insider threat monitoring

Key Platforms:
Microsoft 365

Google Workspace

Microsoft Teams

Zoom

Enhancement:
CASB integration for shadow IT visibility.

🛡️ 2. Cloud Access Security Broker (CASB)
Image

Image

Image

Image

Purpose:
Provides visibility and control over SaaS applications (sanctioned & unsanctioned).

Core Capabilities:
Shadow IT discovery

SaaS risk assessment

Data loss prevention

Session control

User behavior analytics

Compliance enforcement

Tools:
Skyhigh Security

Microsoft Defender for Cloud Apps

🖥️ 3. Cloud Workload Protection Platform (CWPP)
Image

Image

Image

Image

Purpose:
Protects cloud workloads (VMs, containers, serverless, Kubernetes).

Covers:
Runtime protection

Vulnerability management

Container image scanning

EDR/XDR for cloud

Host-based firewall

Compliance monitoring

Tools:
Microsoft Defender for Cloud

Prisma Cloud

Aqua Security

CrowdStrike Falcon

📊 4. Cloud Security Posture Management (CSPM)
Image

Image

Image

Image

Purpose:
Continuously monitors cloud configuration and compliance posture.

Identifies:
Misconfigured storage (public buckets)

Open security groups

Weak IAM roles

Compliance violations (ISO, PCI, CIS benchmarks)

Tools:
CloudGuard

Azure Security Center

AWS Security Hub

Google Cloud Security Command Center

Lacework

Image

Image

Protect sensitive data in cloud environments.

Controls:
Encryption at rest & in transit

Key management

Secrets management

Tokenization

Hardware Security Modules (HSM)

Tools:
Azure Key Vault

AWS Key Management Service

Entrust

Thales Group

👤 6. Cloud IAM & Identity Entitlement Management (IEM)
Image

Image

Image

Image

Purpose:
Control who has access to what, and enforce least privilege.

Covers:
Role-based access control (RBAC)

Privileged Access Management (PAM)

Identity governance

Just-in-Time access

Access certification

Tools:
Microsoft Entra ID

Saviynt

CyberArk

SailPoint

Orca Security

Image

Image

DAST

📈 8. Monitoring & Threat Detection
Image

Image

Image

Image

Purpose:
Provide end-to-end visibility across infrastructure, applications, and users.

Capabilities:
Log monitoring

Behavioral analytics

Alerting & automation

Tools:
Dynatrace

Datadog

🔎 How These Tools Work Together (Security Architecture Flow)
IAM controls identity access

CASB monitors SaaS usage

CSPM checks misconfigurations

CWPP protects workloads

Data Security encrypts assets

DevSecOps secures application pipeline

Monitoring tools detect threats

Alerts feed into SIEM/SOC for response
